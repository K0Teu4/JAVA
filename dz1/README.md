В каталоге находятся два самостоятельных Maven-модуля с решениями ДЗ1.

## Модули

### [hw01OrderFlow](hw01OrderFlow/README.md)

Задачи 1 и 2 по OrderFlow:

- новый тариф `SameDayDelivery` и отказ от проверок конкретных типов тарифов;
- индивидуальная часть A6 — `PaidOnlySalesReport`;
- индивидуальная часть Б1 — статус `DELIVERED`.

### [hw01bank](hw01bank/README.md)

Задача 3 — банковская модель:

- `Amount` и `Account`;
- дебетовые и кредитные счета;
- команды `Deposit`, `Withdraw`, `Transfer`;
- журнал операций `Ledger` с отменой.

## Общая сборка

Требуется Java 21 и Maven.

Запустить тесты обоих модулей из корня репозитория:

```bash
mvn --batch-mode --no-transfer-progress -f dz1/pom.xml clean test
```
