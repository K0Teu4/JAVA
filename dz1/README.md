## Индивидуальный вариант
- **A6 — `PaidOnlySalesReport`:** в отчёт включаются только оплаченные заказы; все строки, итоговое количество, экспресс-счётчик, выручка и крупнейший заказ вычисляются по отфильтрованной выборке.
- **Б1 — `DELIVERED`:** добавлен переход `SHIPPED → DELIVERED`; статус терминальный и имеет `paid() == true`.

## Общие задачи
- `SameDayDelivery`: стоимость 900 руб. при любой сумме, срок 0 дней, уведомление «Экспресс-доставка: привезём сегодня.».
- Удалено знание о конкретных тарифах из `SalesReport` и `ConsoleNotifier`: признак экспресса и текст уведомления предоставляются интерфейсом `DeliveryTariff`.
- Реализован банковский модуль: суммы, дебетовые/кредитные счета, команды операций, атомарный перевод и журнал отмен.
