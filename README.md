### Что реализовано

#### Задача 1. Тариф без проверки конкретного класса
- Добавлен `SameDayDelivery`: фиксированная стоимость 900 руб., срок 0 дней.
- `ExpressDelivery` и `SameDayDelivery` самостоятельно объявляют себя экспресс-тарифами через контракт `DeliveryTariff`.
- Тариф возвращает текст обещания для уведомления о создании заказа: завтра для обычного экспресса и сегодня для доставки в день заказа.
- `SalesReport` и `ConsoleNotifier` не проверяют конкретные классы тарифов через `instanceof`/сравнение типов.

#### Задача 2А. PaidOnlySalesReport
- Добавлен `PaidOnlySalesReport(OrderRepository)`.
- В отчёт попадают только заказы, у которых `status().paid()` возвращает `true` (включая `SHIPPED` и `DELIVERED`).
- Фильтр применяется ко всем строкам и итогам: количеству, экспресс-заказам, выручке и крупнейшему заказу.
- `SalesReport.render()` остаётся `final`; выборка вынесена в расширяемый hook `selectedOrders()`.
- Существующие `TextSalesReport` и `CsvSalesReport` сохраняют прежнюю выборку всех заказов.

#### Задача 2Б. DELIVERED
- Добавлен переход `SHIPPED → DELIVERED` через `Order.deliver()`.
- Другие переходы в `DELIVERED` запрещены.
- `DELIVERED` — терминальный статус и считается оплаченным.
- Запрещённые переходы выбрасывают `IllegalStateException`, не меняя состояние.

#### Задача 3. Банковский счёт
- Реализованы неизменяемый value object `Amount` и сущность `Account` с равенством по `AccountId`.
- Реализованы дебетовый счёт и кредитный счёт с лимитом.
- Реализованы команды `Deposit`, `Withdraw`, `Transfer` и журнал `Ledger`.
- Перевод компенсирует первую операцию, если вторая часть выполнения/отмены завершается ошибкой.
- Журнал запоминает только успешно выполненные команды; неудачная отмена оставляет команду в журнале.
